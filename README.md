# HeartDiseasePrediction_ml
❤️ Heart Disease Prediction System
🎯 Objective

Build a machine learning system to predict whether a patient has heart disease based on clinical and vital health parameters. The project also focuses on exploring the dataset to understand feature importance.

📊 Dataset

The dataset contains patient health records related to heart disease.

Key features include:

Age and sex

Chest pain type

Resting blood pressure

Serum cholesterol

Fasting blood sugar

Resting ECG results

Maximum heart rate achieved

Exercise-induced angina

ST depression (oldpeak)

Slope of peak exercise ST segment

Target variable:

class → 0 = Normal, 1 = Heart Disease

🛠️ Tools & Technologies

Python

Pandas, NumPy

Matplotlib, Seaborn

Scikit-learn

🔍 Workflow

Data loading and preprocessing

Exploratory Data Analysis (EDA)

Feature encoding and scaling

Model training and evaluation

Heart disease prediction

✅ Outcome

A trained machine learning model that predicts the presence of heart disease and helps identify key risk factors.
